# Запуск фронтенду локально

Спочатку запустити БД та бекенд за **TEAM-LOCAL.md у репозиторії API**.
Python і venv потрібні бекенду, не цьому UI.

Відкрити другий PowerShell-термінал **у папці lnurepo-ui**.
Кожен блок — одна команда.

## 1. Залежності — перший запуск / оновлення package-lock.json

~~~powershell
npm ci
~~~

## 2. Запуск фронтенду

~~~powershell
npm run dev:team
~~~

Відкрити **http://127.0.0.1:5173** → «Увійти як тестовий користувач».
Термінали бекенду та фронтенду залишити відкритими. Зупинка — Ctrl+C.
При наступному запуску достатньо другої команди, якщо залежності не змінилися.

.env.team вже містить локальний URL API. Не підміняти його production URL.
Для перегляду тільки дизайну без API/БД є npm run dev:preview.
Production build — npm run build, без --mode team.
Працювати в окремій гілці та передавати зміни через Pull Request.
